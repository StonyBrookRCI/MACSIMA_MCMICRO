# MCMICRO for MACSima on NVwulf

This repository contains the scripts and configuration files required to process MACSima spatial proteomics data using the MCMICRO pipeline on the NVwulf high-performance computing (HPC) cluster.

This workflow was specifically optimized for Tissue Microarray (TMA) analysis of Pancreatic Ductal Adenocarcinoma (PDAC). A sample taken from the Stony Brook University Department of Pathology, the pipeline is tailored to quantify the spatial dynamics of the Epithelial-Mesenchymal Transition (EMT).

## 🔬 Overview

Processing MACSima data involves converting raw cyclic imaging data into a format MCMICRO can understand, performing image registration, and executing single-cell segmentation, quantification, and downstream analysis.

### Key Technical Notes

- **Raw Data Focus:**  
  These scripts utilize the `RawData` folder generated by the MACSima instrument. We do **not** use the `PreprocessedData` folder.

- **Exposure Handling:**  
  The instrument generates two different exposure levels for each cycle, we use the high exposure images in this workflow as recommended by Miltenyi. While MACS IQView uses these for HDR to combine both high and low exposure images. It is generally recommended to use the high-exposure images only, which are the input to the MCMICRO pipeline.

- **Segmentation:**  
  This specific implementation uses Cellpose for primary nuclei and cell segmentation. But other segmentation methods are available, and trained on different tissue types.

> [!NOTE]
> While a dedicated `nf-core/mcmicro` pipeline is currently under development, it is still incorporating modules that are already fully functional in the original framework. Therefore, this documentation utilizes the native MCMICRO Nextflow pipeline, as its outputs are fully validated and comprehensive. Once the official nf-core implementation reaches stable release and feature parity, we will update this workflow accordingly.

## 🛠 Prerequisites

Before running the analysis, ensure you have access to the NVwulf cluster and that the following files are in your working directory:
- `staging.sh`
  Adjust the job array number `#SBATCH --array=1-28` to the number of lines in acquisitions.tsv

- `acquisitions.tsv`  
  A tab-separated file mapping Slurm array indices to individual MACSima sample directories. This file is used by `staging.sh` to determine which acquisition folder each array task should process.

- `samples.tsv`  
  A tab-separated file mapping Slurm array indices to individual exp for MCMICRO sample directories. This file is used by `mcmicro_macsima.sh` to determine which raw folder each array task should process.

- `mcmicro_macsima2mc.sh`
  Adjust the job array number `#SBATCH --array=1-55` to the number of lines in samples.tsv
  
- `nvwulf.config`  
  A required Nextflow configuration file that defines the SLURM settings, GPU resource allocations, and Singularity container paths specific to the NVwulf environment.

- `params.yml`  
  Defines the MCMICRO workflow steps (e.g., starting at registration, stopping at downstream analysis), and command flags.

- `markers.csv`  
  Maps the imaging channels and cycles to specific antibody markers. Used for the example run with mcmicro_example.sh.

## 🚀 Execution Guide

### 1. Data Staging (`staging.sh`)

The first step is to reorganize the MACSima raw data into a structure compatible with MCMICRO. This script uses the `macsima2mc` tool to process the raw folders.

#### Usage

Submit the staging script as a Slurm array job:

```bash
sbatch staging.sh
```

#### What it does

It iterates through the `RawData` cycles and prepares the OME-TIFF files required for the registration step.

---

### 2. Running the Pipeline (`mcmicro_macsima2mc.sh`)

Once the data is staged, you can run the full MCMICRO pipeline. This script orchestrates the computational heavy lifting, including:

- **Registration:** Aligning the cyclic images using ASHLAR
- **Segmentation:** Using Cellpose (utilizing NVwulf GPUs)
- **Quantification:** Extracting intensity data for every cell

#### Usage

```bash
sbatch mcmicro_macsima2mc.sh
```

---

### 3. Testing with Example Data (`mcmicro_example.sh`)

If you are new to the cluster or the pipeline, it is recommended to run the included `mcmicro_example.sh`.

This uses a small, validated dataset and the `markersheet.csv` to ensure your environment and the `nvwulf.config` are set up correctly.
